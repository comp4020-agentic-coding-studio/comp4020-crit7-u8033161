# Crit 7 reflection

## The breakthrough

This week I changed my topic twice before I found one that held up.

My first idea was a deadline board, because Canvas reminders were easy
to miss. But when I took screenshots to prove it, I found the Agenda view
in Canvas already shows only the things I need to submit. The problem was
real to me, but the feature already existed. It felt like a stretch.

My second idea was a tutorial swap board. I thought MyTimetable had no
way for two students to swap. Then I asked Claude to check ANU's own
guide, and the heart button turned out to be "Request Swap". The system
already matches swaps for you. I was wrong again.

The third idea came from my own experience as a Master of Computing
student. When I choose electives, I can't tell if I'm ready for a course.
The COMP6261 page just says "130 hours". So I usually have to sit through
the first two weeks to find out. This time I checked first: SELT only
gives 1–5 scores, and StudentVIP has almost no postgrad reviews. The gap
was real, so I built it.

## What it changed about me

Before, I started building as soon as an idea sounded right. Now I want
to check the problem first, with evidence, before I write any code.

I also kept this rule inside the app. The agent was not allowed to invent
any student reports, and the weekly hours figure says clearly that it's
my app's estimate, not an official number.
